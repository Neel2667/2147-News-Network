# Pilot Episode Package — 2147-001

## Episode

**Mars Votes for Independence From Earth | 2147 News Network**

## Purpose

This is the first pilot episode package for 2147 News Network. It establishes the channel's premium broadcast style, realism rules, causal event system, and the first season's main storyline: the Mars sovereignty crisis.

## Core Event

`event_2147_001_mars_referendum_final_cycle`

Mars enters the final voting cycle in its independence referendum.

## Required Quality Standard

This episode must look like an international-level news broadcast from the future:

- Apple-inspired premium UI
- beautiful typography
- clean glass panels
- smooth animations
- no cheap cyberpunk clutter
- named people and institutions
- source labels and timestamps
- causal history and ripple effects

## Files

```text
production_package.json   Complete structured package
scene_plan.json           Timeline scenes for the app
script.md                 Anchor/narration script
metadata.json             YouTube metadata draft
production_notes.md       Visual/audio/editorial notes
```

## Recommended First Production Workflow

1. Load or generate the draft in 2147 News Network Studio.
2. Open Scene Timeline.
3. Load/save episode ID `2147-001-mars-independence`.
4. Preview each scene.
5. Tune lower-thirds, tickers, source labels, and duration.
6. Export draft files.
7. Record/render web templates.
8. Edit final video with voiceover and sound design.
