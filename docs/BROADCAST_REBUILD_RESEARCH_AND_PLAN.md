# Broadcast Rebuild Research and Plan — V2

Last updated: 2026-06-16

## Why We Are Rebuilding

The first demo looked like a generic sci-fi motion graphic, not a serious news channel. The new direction must look like a real international broadcast package.

## Research Takeaways

Modern TV news graphics work as a structured broadcast system, not random cinematic screens. Common elements:

- persistent channel bug / logo
- LIVE indicator
- clock / location / source labels
- lower thirds / name straps
- headline straps
- ticker / crawl
- full-screen explainers
- split screens
- over-the-shoulder graphics
- data boards
- map boards
- reusable templates
- real-time editable text/data
- broadcast safe margins

## New Design Target

```text
International news control-room package
+ Bloomberg/BBC/Al Jazeera clarity
+ future 2147 details
+ restrained premium motion
```

Not:

```text
sci-fi wallpaper
random planets everywhere
generic cyberpunk UI
AI-looking dashboard
```

## Mandatory V2 Rules

1. Every frame must look like a real broadcast screen.
2. Use lower thirds, headline straps, and tickers like actual TV news.
3. Use large readable typography.
4. Keep persistent bug/logo and LIVE metadata.
5. Use story panels and data graphics, not abstract decorative scenes.
6. No more generic full-screen sci-fi visuals without newsroom function.
7. Motion should be broadcast motion: wipes, slides, straps, board reveals, data count-ups.
8. Use source labels and timestamps on every major graphic.
9. Preserve safe margins for YouTube/mobile viewing.
10. If a scene does not help journalism/story comprehension, remove it.


## V2 Typography Strategy

- Use strong condensed bold for headlines.
- Use clean sans-serif for supporting text.
- Lower thirds must be readable on mobile.
- Avoid tiny sci-fi labels.
