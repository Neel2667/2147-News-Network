# Visual Policy — No AI Images or Videos

## Absolute Rule

This project does not use AI-generated images or AI-generated videos.

## Allowed Visual Sources

### Web-Rendered Graphics

Allowed and preferred:
- HTML
- CSS
- SVG
- Canvas
- WebGL
- procedural particles
- charts
- maps
- dashboards
- UI panels
- tickers
- lower-thirds

### Public-Domain Media

Allowed if license permits:
- NASA media
- other government/public-domain footage
- Wikimedia Commons public-domain assets

### Stock Footage

Allowed if license permits and asset is not AI-generated:
- Pexels
- Pixabay
- Mixkit
- Videvo
- Storyblocks
- Envato
- Artgrid

### Self-Shot Footage

Allowed and encouraged:
- city streets
- buildings
- rain
- screens
- typing hands
- traffic
- construction
- skies
- ocean/water

## Forbidden Visual Sources

Do not use:
- AI-generated future city images
- AI-generated video clips
- AI avatars
- AI-generated photorealistic humans
- AI-generated alien/planet backgrounds
- AI-generated thumbnails

## Disclosure

Each YouTube description should include:

> This is a fictional speculative news broadcast set in the year 2147. Created for entertainment and worldbuilding purposes.
