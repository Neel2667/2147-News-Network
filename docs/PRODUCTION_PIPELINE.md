# Production Pipeline

## Per-Episode Workflow

### 1. Choose Topic

Examples:
- Mars independence
- neural privacy law
- robot labor strike
- Europa probe signal
- Pacific superstorm
- lunar oxygen-credit crisis

### 2. Generate Headlines

Create 5–7 fictional future headlines from 2147.

### 3. Select Main Story

Choose the story with the strongest conflict, stakes, and visual potential.

### 4. Generate Script

Script sections:
- anchor opening
- headline montage
- main story context
- data segment
- fictional quote/expert analysis
- secondary headlines
- closing

### 5. Create Scene Plan

Each scene needs:
- scene title
- duration
- template
- narration
- on-screen text
- ticker text
- footage notes
- visual notes

### 6. Produce Voiceover

Options:
- creator voice
- hired voice actor
- licensed TTS

### 7. Render Visuals

Use:
- browser-based templates
- OBS recording
- optional Playwright screenshots/frame capture
- optional FFmpeg assembly

### 8. Edit Final Video

Use DaVinci Resolve, Premiere, CapCut, or FFmpeg.

### 9. Upload

Include title, description, tags, disclaimer, and thumbnail.

## MVP Manual Render Workflow

1. Open HTML preview in browser.
2. Record scene with OBS.
3. Import clips into editor.
4. Add voiceover and music.
5. Add subtitles.
6. Export MP4.
