## Major Strategic Decisions

The user asked if the channel should run 24/7 or release episodes.

Recommendation given:

1. Start with polished episodes first.
2. Build the fictional world and event continuity.
3. Create shorts and daily briefings.
4. Launch 24/7 stream later after enough content exists.

Reason:

- better for YouTube growth

## Causal Event Engine Decision

The user proposed that in the real world, one event is caused by earlier events and then creates ripples that generate future events.

This became the central architecture:

```text
past event → current event → reaction → ripple → future event
```

The channel should not simply generate random fictional news. It should analyze a fictional world state and generate news from causal consequences.

Example chain:

```text
2136: Lunar oxygen-credit protests
↓
2142: Mars challenges Earth cargo tariff authority
↓
2147: Mars enters final voting cycle in independence referendum
↓
Earth Union Senate schedules emergency sovereignty hearing
↓
Helion Grid Systems CEO Jiang Lau warns of market instability
↓
Lunar Workers Guild expands oxygen-credit demands
↓
Synthetic Rights Tribunal receives AI voting-rights petition
```

This system should be implemented through `data/events.json` and expanded over time.
