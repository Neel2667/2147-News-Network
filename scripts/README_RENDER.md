# Render Scripts Placeholder

The app currently creates video-ready standalone HTML scene pages and a manifest.

Recommended first method:

1. Create render package in the app.
2. Open scene pages from `/renders/{package_id}/scenes/`.
3. Record with OBS at 1920×1080.
4. Assemble in a video editor.

Future scripts can be added here for:

- Playwright frame capture
- FFmpeg assembly
- subtitle burn-in
- audio sync
